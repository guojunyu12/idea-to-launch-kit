# 阶段2-2技术开发文档

产品：AIGC 内容生成平台（我的第一个产品）
PRD：V7
阶段：2-2 用户生成主链路
更新时间：2026-11-12

## 1. 本阶段目标

把 V7 的核心用户生成链路落到后端：已发布模板 + 用户文字提示词 + 输出尺寸 + 已启用模型 → 持久化生成记录 → 真实生图 → 结果下载。生成任务绑定登录用户，免费额度和积分扣减必须可追踪，失败时积分返还；旧版上传/任务接口继续兼容。

## 2. 本阶段交付

- 新增 `generations` 持久化记录，保存模板版本、提示词快照、模块、尺寸、模型、状态、成本、额度使用和失败返还状态。
- 新增 `GET /api/v1/models`，只返回已启用且可用于用户生成的模型；启动时按本地配置确保 `qwen-image-2.1-turbo` 为默认模型。
- 新增 `POST /api/v1/generations`、查询列表/详情和结果下载接口；接口要求邮箱会话，模板必须是 `published`。
- 支持常用比例和 256–4096 px 的自定义宽高；比例必须在 0.25–4.0 范围内。
- 每个用户每天 3 次免费生成；免费额度用尽后仅在积分足够时扣 1 积分。扣减、生成成功、失败返还和审计均写入持久化记录。
- 使用请求幂等键避免重复调用模型；其他用户读取生成记录和结果统一返回 404。
- Qwen-Image、SenseNova 和 mock Provider 统一支持用户提示词；真实链路使用阿里云百炼 DashScope 的 `qwen-image-2.1-turbo`。
- `/test` 增加 V7 点击式验收区，产品经理不需要填写 API：登录、选模板、写提示词、选尺寸、生成并查看结果。

## 3. 主要接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/v1/models` | 获取可用生图模型 |
| POST | `/api/v1/generations` | 登录用户提交一次生成；支持 `template_id`、`prompt`、`aspect_ratio` 或 `width/height`、`model_id`、`idempotency_key` |
| GET | `/api/v1/generations` | 查看当前用户最近生成记录 |
| GET | `/api/v1/generations/{id}` | 查看当前用户的一条生成记录 |
| GET | `/api/v1/generations/{id}/asset` | 下载当前用户自己的 PNG 结果 |

生成成功返回 `status=succeeded`、结果尺寸、模型、是否使用免费额度、扣除积分和结果地址。模型失败返回统一错误 `GENERATION_FAILED`，积分记录为 `refunded`。

## 4. 可靠性与边界

- 后端强制校验会话、模板发布状态、模型启用状态、模块绑定和尺寸范围；前端不持有模型 Key。
- `idempotency_key` 按用户隔离；重复提交返回原生成记录，不重复扣额度或调用模型。
- Qwen 返回的图片先由 Pillow 解码，再按用户目标尺寸归一化为 PNG。
- 日志只记录任务 ID、模板 ID、模型、尺寸、耗时、成本和错误类型，不记录 Key 或完整提示词。
- 本阶段不接用户生成结果内容审核；模板审核/发布后台窗口已在前阶段保留。
- 本阶段不做正式邮件服务、支付、并发压测和正式前端；这些内容按路线图留在后续阶段。

## 5. 验证结果

- mock 自动化测试：26 条通过。
- 真实 Qwen 端到端：登录、读取已发布模板、提交文字提示词和 512×512 自定义尺寸、真实生成、PNG 下载、跨用户 404 均通过。
- 真实结果由 `scripts/smoke_real.py` 自动写入 `docs/evidence/阶段2-2/冒烟记录.md`，图片保存为 `真实模型结果.png`。
