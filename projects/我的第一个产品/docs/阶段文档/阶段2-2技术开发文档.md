# 阶段2-2技术开发文档

产品：图个乐  
阶段：2-2 供应商适配与可靠生成  
更新时间：2026-11-08

## 1. 本阶段目标

在 2-1 的任务、版本、上传和下载基础上，补齐供应商适配的可靠性：商汤 SenseNova 真实调用、`url`/`b64_json` 双返回解析、瞬态错误重试、结果尺寸归一化，以及可重复的真实冒烟记录。

## 2. 本阶段交付

- `SenseNovaProvider`：供应商无关的内部 Provider 接口实现。
- 商汤配置：Base URL、模型、超时、重试次数和退避时间均由 `.env` 控制。
- 瞬态 HTTP 状态 `429/500/502/503/504` 和网络传输错误最多重试 2 次，退避时间指数增长。
- 兼容商汤返回的 `b64_json` 与临时 `url`，不把远端 URL 直接写入交付记录。
- 用 Pillow 解码并按模板目标尺寸归一化，输出统一为 PNG；wallpaper 结果实测为 1179×2556。
- 成功任务删除原图文件，保留上传记录的状态、哈希和审计记录。
- `scripts/smoke_real.py` 自动写入真实冒烟记录和结果图，不在记录中写入 Key。
- `/test` 轻量测试工作台：同源完成选模板、上传、生成和结果预览；它是验收工具，不是正式 Next.js 前端。

## 3. 当前供应商决策

这枚 Key 的 `/models` 目录实际返回 `sensenova-u1.5-lite`，未返回 PRD 附带文档中的 `sensenova-u1-fast`；因此本地 `.env` 使用 `sensenova-u1.5-lite`。模型名不硬编码在业务路由中，换供应商只替换 Provider 和配置。

当前商汤调用是文生图。上传照片用于验证上传、归属和原图删除链路，没有作为参考图发送；人物相似度和图生图能力留到支持图像输入的后续 Provider。

## 4. 验收结果

- mock 测试：11/11 通过。
- 真实商汤：健康检查、上传、生成、结果下载、1179×2556 尺寸和跨用户 404 均通过。
- 重试：单元测试模拟 429 后恢复，确认会再次请求。
- 密钥：本地 `.env` 权限为 600，未被 Git 跟踪，verify 扫描通过。
