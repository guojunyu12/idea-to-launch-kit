# 阶段2-3技术开发文档

产品：AIGC 内容生成平台（我的第一个产品）
PRD：V7
阶段：2-3 管理工作台与结果生命周期
更新时间：2026-11-12

## 1. 本阶段目标

把模板和模型配置从基础表升级为可管理的后台契约，并补齐生成结果的删除、清理、审计和用量查询。普通用户只读已启用模型和已发布模板；运营/管理员通过独立的后台接口管理配置。

## 2. 本阶段交付

- 管理员新增、编辑模型配置，可设置供应商、模型 ID、启用状态、默认路由、模块绑定、支持比例、积分和成本。
- 运营/管理员查看全部模型配置；未启用模型保留在后台，不进入普通用户列表。当前本地默认模型为商汤 `sensenova-u1.5-lite`，千问配置继续保留。
- 运营/管理员查看模板版本、全局审计和用量摘要。
- 登录用户可以删除自己的生成结果；结果文件立即删除，记录保留为 `deleted`。
- 运营/管理员可手动调用 7 天结果清理接口，过期结果保留元数据并标记 `expired`。
- 生成结果和后台操作继续按用户/角色隔离，模型密钥只从环境变量读取。

## 3. 主要接口

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/v1/admin/models` | 运营/管理员 | 查看全部模型配置 |
| POST | `/api/v1/admin/models` | 管理员 | 新增模型配置 |
| PATCH | `/api/v1/admin/models/{model_id}` | 管理员 | 修改启用、默认、优先级、模块和成本 |
| GET | `/api/v1/admin/templates/{id}/versions` | 运营/管理员 | 查看模板版本 |
| GET | `/api/v1/admin/audit` | 运营/管理员 | 查看全局审计事件 |
| GET | `/api/v1/admin/usage` | 运营/管理员 | 查看任务总量、成功/失败/删除和模型分布 |
| DELETE | `/api/v1/generations/{id}` | 结果所属用户 | 删除自己的结果 |
| POST | `/api/v1/admin/cleanup?retention_days=7` | 运营/管理员 | 标记并清理过期结果文件 |

## 4. 安全与一致性

- 普通用户访问后台模型、模板版本、审计和用量接口统一返回 `ROLE_FORBIDDEN`。
- 管理员设置默认模型时自动取消其他默认标记；模型配置修改写入审计事件。
- 删除只影响当前用户自己的生成记录；文件删除后结果下载返回 404，数据库记录保留用于审计。
- 测试导入模块时不会用隐式 mock 默认覆盖已经配置的真实供应商，避免本地测试污染生产配置。
