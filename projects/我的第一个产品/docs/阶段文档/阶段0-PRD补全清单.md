## 已发现的矛盾与处理

- 旧版 D5 是邀请码会话，V7 FR1 改为邮箱验证码登录；按本轮确认改为固定邮箱白名单的后台/管理权限，普通用户走邮箱验证码。
- 旧版 D8 是暂不接入内容审核；按本轮确认，V7 只审核模板，用户生成结果暂不审核。
- 旧版产品名和当前代码目录是“图个乐 / 我的第一个产品”，V7 产品名是“AIGC 内容生成平台”。根据规则，已有项目目录不改名；后续页面和 README 是否改品牌名列入技术适配阶段处理。
- V7 写了 SenseNova 6.8 Flash Lite 配置示例，但当前真实冒烟使用的是 `sensenova-u1.5-lite`；模型是否切换必须等供应商能力和成本核实，不能只按名称替换。
