# 阶段 3-2 技术开发文档：移动端与响应式质量

## 1. 本阶段目标

产品经理可以在手机浏览器中从一级分类页进入表情包或手机壁纸二级页，完成模板选择、输出比例选择、照片上传、生成结果查看和下载；页面在 390px、768px、1280px 和 1440px 宽度下不出现无意横向滚动。

## 2. 范围

### 本阶段包含

- 一级页 `/` 的手机布局与分类导航。
- 二级页 `/category/sticker`、`/category/wallpaper` 的手机布局与分类切换。
- 390px 移动端的模板横向浏览、比例选择、上传区、结果区和审核后台预留位。
- 触控目标、键盘焦点、表单标签、错误提示和加载状态的检查。
- 使用真实后端 API 的生成链路回归。

### 本阶段不包含

- 内容审核规则和后台管理功能；只保留 V1 审核后台窗口。
- 登录、线上部署和腾讯云资源配置。
- 新增模板管理、历史记录管理或模型切换页面。

## 3. 用户流程

1. 手机打开一级页，看到“表情包”和“手机壁纸”两个分类入口。
2. 点击一个分类，进入对应二级页；顶部第二行导航仍可切换到其他分类。
3. 选择图片参考模板，确认模板标题和目标尺寸。
4. 在输出比例下拉框中选择比例，确认当前输出尺寸同步变化。
5. 上传 JPG、PNG 或 WebP 图片，点击提交箭头。
6. 等待上传和生成状态变化，查看真实结果与任务信息。
7. 点击“下载作品”，保存生成图片。

## 4. 页面状态矩阵

| 状态 | 一级分类页 | 二级创作页 |
|---|---|---|
| idle | 分类入口可点击 | 模板、比例和上传入口可操作 |
| submitting | N/A | 提交按钮禁用，开始上传 |
| queued | N/A | 由后端任务状态承接，页面显示处理中 |
| running | N/A | 显示“正在生成” |
| streaming | N/A | N/A，当前接口返回完整图片结果 |
| waiting_user | N/A | N/A |
| succeeded | N/A | 结果图片、任务信息和下载按钮可见 |
| partially_succeeded | N/A | N/A |
| failed | 模板接口失败时显示空状态 | 错误提示保留，允许重新选择并提交 |
| cancelled | N/A | N/A |
| disconnected | N/A | 请求失败时显示可理解的生成失败提示 |
| stale | N/A | 刷新后回到可重新创建状态 |
| loading（数据加载中） | 模板数量显示读取中 | 显示“正在读取模板…” |
| empty（请求成功但无数据） | 使用空占位，不伪造模板 | 当前品类无模板时保留空状态 |
| permission_denied | N/A | 后端错误按统一错误结构显示 |
| not_found | N/A | 非法品类回退到表情包二级页 |

## 5. 接口契约

- `GET /api/v1/templates`：读取模板库，一级页按 `kind` 取分类参考图，二级页只保留当前品类。
- `POST /api/v1/uploads`：上传 JPG、PNG 或 WebP，后端校验真实格式、尺寸和大小。
- `POST /api/v1/tasks`：携带 `template_id`、`upload_id`、`owner_id` 和 `aspect_ratio` 创建任务。
- `GET /api/v1/tasks/{task_id}`：读取任务、版本、产物地址和输出尺寸。
- `GET /api/v1/assets/{version_id}`：下载生成图片。
- 错误统一由前端显示 `error.message`；网络失败显示“生成失败，请稍后再试”。
- 当前生成接口是同步等待结果，前端用上传中 / 生成中 / 已完成三段状态表达，不伪造排队进度。

## 6. 实现方案

- 路由：`/` 一级分类页；`/category/[kind]` 二级品类页。
- 响应式处理：桌面使用居中顶部导航和横向模板区；900px 以下保留二行分类导航；600px 以下改为单列、横向模板卡和纵向创作表单。
- 移动端导航：显示“全部 / 表情包 / 手机壁纸”三项可点击入口，隐藏无实际动作的右侧控制，避免用户被困在二级页。
- 触控与焦点：链接、按钮和圆形提交入口保持可触达尺寸；所有核心控件有可访问名称和 `focus-visible` 样式。
- 状态来源：React 本地状态承接模板、文件、任务、结果和错误；业务数据仍由后端持久化。
- 安全和隐私：API Key 仍只在后端 `.env`；上传照片只用于当前任务；页面保留“审核后台窗口已预留 / V1 暂不启用内容审核”。

## 7. 验收标准

- Given 手机宽度为 390px，When 打开 `/`，Then 两个分类入口单列展示且无横向滚动。
- Given 手机打开 `/category/sticker`，When 查看顶部，Then 能看到全部、表情包、手机壁纸三项导航并可互相切换。
- Given 选择模板和比例，When 更换比例，Then “当前输出尺寸”同步更新。
- Given 选择有效照片，When 提交，Then 页面显示上传中、生成中和完成状态，并展示真实生成结果。
- Given 生成完成，When 点击下载，Then 浏览器可保存图片。
- 目标宽度：390px、768px、1280px、1440px。
- 自动检查：`bash kit.sh 自检 我的第一个产品`。

## 8. 风险与回退

- 风险：手机真机访问本机服务需要同一 Wi-Fi 和局域网地址；本阶段不涉及摄像头或麦克风，因此不需要本地 HTTPS。
- 降级方案：若真实模型暂时不可用，可保留已验证的 mock 模式，但阶段验收仍以真实冒烟记录为准。
- 回退方式：移动端导航只改 CSS，桌面页面结构和 API 契约不变，可回退到上一版样式。

- 检查结果：390px 页面截图、分类切换、无横向滚动检查已完成；前端 lint、类型检查、测试、构建和真实冒烟在阶段收尾时重新执行。
