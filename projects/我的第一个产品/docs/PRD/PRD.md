## 1. 产品定位与目标

这是一个模板驱动的 AIGC 图片生成平台。用户从已发布模板中选择表情包、手机壁纸或电脑壁纸，输入自己的提示词，选择尺寸和可用模型后生成图片。运营人员在独立的管理工作台中负责模型配置、模板来源管理、内容审核、版本更新、发布和用量成本监控。

V1 只做静态图片，不做生视频、文章、营销文案或社交媒体文字生成。

## 2. 角色与权限

| 角色 | 权限 |
|---|---|
| 普通用户 | 邮箱登录；浏览已发布模板；输入提示词；选择尺寸和模型；生成、下载、删除自己的图片；查看自己的积分和生成记录 |
| 运营人员 | 进入管理工作台；抓取或人工导入候选模板；查看来源和版权信息；进行内容审核；通过、驳回、修改和发布模板；查看模板版本、发布结果和用量报表 |
| 管理员 | 包含运营人员权限；新增、编辑、停用和切换模型；配置供应商、接口、成本、限额和模块绑定；管理角色权限和系统配置 |

用户端和管理工作台使用独立入口和导航。普通用户不显示管理能力，运营操作不进入用户端流程。

## 3. 核心用户流程

### 3.1 用户端生成流程

1. 用户使用邮箱验证码登录。
2. 用户选择模块：表情包、手机壁纸、电脑壁纸。
3. 用户从已发布模板库中选择模板。
4. 模板提供默认风格、构图和基础提示词。
5. 用户在对话框输入自己的主题或画面要求，可修改或追加提示词。
6. 用户选择模块推荐尺寸，或输入安全范围内的自定义宽高。
7. 用户选择已启用的生图模型。
8. 系统校验登录状态、剩余额度、积分、模板状态、尺寸和模型状态。
9. 生成成功后返回图片，记录模板版本、用户提示词、模型、尺寸、积分、Token 和成本。
10. 用户可下载或删除图片；图片默认保存 7 天。

V1 支持一次输入一次生成。连续对话改图、参考图和局部重绘列为后续版本。

### 3.2 模板供给与审核流程

外部来源或人工导入 → 候选区 → 版权与内容审核 → 通过 → 创建模板版本 → 发布到用户端。

未审核候选模板不能被用户使用，不能进入正式模板库，不能推送上线。

## 4. 功能需求

| 编号 | 功能 | 验收要求 |
|---|---|---|
| FR1 | 邮箱登录 | 未登录用户不能生成图片；登录状态可追溯到用户 ID |
| FR2 | 模块模板库 | 按表情包、手机壁纸、电脑壁纸分类展示已发布模板 |
| FR3 | 模板提示词 | 模板保存默认提示词、风格参数和版本；用户提示词可覆盖或追加 |
| FR4 | 用户提示词输入 | 选完模板后可在对话框输入自己的提示词；生成记录保存提示词快照 |
| FR5 | 尺寸选择 | 每个模块有推荐尺寸；用户可在 256–4096 px、比例 0.25–4.0 范围内自定义 |
| FR6 | 图片生成 | 调用已启用且绑定模块的生图模型生成静态图片 |
| FR7 | 图片管理 | 图片保存 7 天；用户可以下载和删除；过期图片自动清理 |
| FR8 | 免费额度与积分 | 每个用户每天免费生成 3 张；建议每次成功生成消耗 1 积分；失败任务不扣积分 |
| FR9 | 自定义模型 | 管理员可新增、编辑、启用、停用和切换任意兼容模型，无需重新部署 |
| FR10 | 模型路由 | 支持默认模型、优先级、备用模型、超时、重试、单次成本、每日限额和模块绑定 |
| FR11 | 模板来源 | 支持小云雀、即梦等 AIGC 平台的官方接口或人工导入；连接器可单独启停 |
| FR12 | 模板审核 | 运营人员可查看来源、版权状态、指纹、批次、审核结论和发布结果 |
| FR13 | 模板版本 | 模板发布和更新产生版本号，用户端只展示已发布版本 |
| FR14 | 用量成本 | 按用户、模块、供应商、模型、模板记录 Token、积分、成本、状态和时间 |
| FR15 | 审计日志 | 记录模型配置变更、审核决定、模板发布、积分变更和管理员操作 |

## 5. 模型配置

后台模型列表提供 Doubao-Seedream、Qwen-Image、SenseNova 6.8 Flash Lite 配置示例，同时允许管理员自定义模型。

每个模型至少配置：

- 模型名称、供应商、模型 ID
- 模型类型：生图、理解、审核、生视频
- API 地址和密钥引用
- 启用状态、默认状态、优先级
- 支持的模块和尺寸比例
- 单次积分、单次成本、每日限额
- 超时、重试次数和备用模型

SenseNova 6.8 Flash Lite 默认按理解、审核或编排模型处理，只有供应商账号提供可验证的图片生成端点时才能绑定生图。理解或审核模型不能直接当作生图模型调用。

密钥只保存为安全配置引用，页面和日志不得显示完整密钥。模型配置的修改需要写入审计日志。

## 6. 模板与内容审核

候选模板需要保存：来源平台、来源 URL、抓取或导入时间、授权/版权状态、原始内容指纹、抓取批次、模块、标题、预览图、审核人、审核时间、审核结论和发布结果。

平台抓取必须使用官方接口或经过授权的方式。未确认允许自动抓取的平台先支持人工导入。运营人员负责最终内容审核，系统可以提供 AI 初筛，但 AI 不能替代人工发布决定。

已发布模板被用户使用时不需要再次审核。模板更新需要创建新版本，并保留旧版本记录。

## 7. 积分、存储与失败处理

- 每个用户每天拥有 3 张免费生成额度，按用户时区每天零点恢复。
- V1 建议一次成功生成消耗 1 积分，实际供应商成本单独记录。
- 校验失败、供应商失败、超时和系统错误不扣积分；已扣积分的失败任务必须自动返还。
- 图片生成结果保存 7 天，用户主动删除后立即从用户列表移除，并在 24 小时内完成物理清理。
- 超出模型每日限额或成本上限时，系统拒绝调用并提示管理员调整配置。

## 8. V1 验收指标

### 8.1 上线硬验收

| 指标 | 目标 | 验证方式 |
|---|---:|---|
| 生图成功率 | ≥95% | 使用有效输入连续执行不少于 100 次生成 |
| 平均生成时间 | ≤2 分钟 | 统计成功任务端到端耗时 |
| 95% 生成任务完成时间 | ≤5 分钟 | 统计 P95 端到端耗时 |
| 并发能力 | 10 人同时生成不崩溃 | 10 个并发任务压测，检查服务、队列和数据一致性 |
| 外部模板审核拦截率 | 100% | 未审核模板无法出现在用户端、无法被生成调用 |
| 审核时效 | 24 小时内完成率 ≥95% | 统计进入候选区到人工结论的时间 |
| 用量账目完整率 | ≥99% | 对比调用记录与 Token、积分、成本台账 |
| 过期清理成功率 | ≥99% | 检查超过 7 天的图片是否自动清理 |
| 积分扣除准确率 | 100% | 成功扣除、失败返还、重复请求不重复扣除 |

### 8.2 上线后运营指标

| 指标 | 首轮目标 | 说明 |
|---|---:|---|
| 首次生成完成率 | ≥60% | 邮箱登录用户中完成首次生成的比例 |
| 7 日再次使用率 | ≥30% | 首次生成用户在 7 天内再次生成的比例 |
| 模板到生成转化率 | ≥20% | 查看模板后完成生成的比例 |
| 模板审核通过率 | 按来源单独观察 | 用于判断抓取来源质量，不设统一硬阈值 |

## 9. 非功能要求

- 用户端和管理工作台入口、导航和权限隔离。
- 10 人并发时服务保持可用，失败任务可重试且不产生重复扣费。
- 所有关键操作可追溯到用户、角色、时间和对象版本。
- 日志、报表和错误信息不得泄露模型密钥。
- 图片、提示词和审核数据按最小权限访问。

## 10. V1 明确不做

- 生视频。
- 文章、营销文案和社交媒体文字生成。
- 连续多轮对话改图。
- 参考图、人物一致性、局部重绘。
- 未授权的平台自动抓取。
- V1 在线支付；先实现免费额度和积分台账。

## 11. 待确认但不阻塞开发的问题

1. 邮箱验证码有效期和发送服务供应商。
2. 不同模型的积分权重是否都按 1 张图 1 积分，还是按成本设置权重。
3. 图片删除后的物理清理时限是否需要缩短到 1 小时。
4. 是否在生成完成后增加一次 AI 内容安全审核。
