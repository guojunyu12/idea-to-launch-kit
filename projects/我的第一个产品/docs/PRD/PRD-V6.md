## 1. 原始需求（逐字保留，不改写）

给爱玩梗、想做专属表情包和壁纸、又不想学写提示词或修图的年轻人用，解决通用 AI 门槛高、出图不稳、也没有后处理的问题——选模板、上传人物照，就能稳定做出定制表情包和适配尺寸的壁纸。

## 2. 需求拆解

| 维度 | 内容 | 来源 |
|---|---|---|
| 目标 | 让不会写提示词、不会修图的年轻人，通过选模板和上传人物照，稳定做出定制表情包或手机壁纸。 | 原始需求；V1 回答 |
| 用户 | 爱玩梗、想做专属表情包和壁纸、又不想学写提示词或修图的年轻人。 | 原始需求 |
| 核心闭环 | 选择表情包或手机壁纸模式 → 选择模板 → 上传人物照 → 生成一张图片 → 下载/保存；支持多轮修改、换模板、局部重绘和历史版本。 | 原始需求；V1 回答 |
| 交付物 | 一张定制表情包或一张适配手机尺寸的壁纸，用户可以下载或保存。 | 原始需求；V1 回答 |
| 边界 | V1 暂不接入内容审核，允许先走创作与交付闭环；预留审核后台窗口和接口位置，后续再接入审核与投诉处理。模板后台管理窗口预留，未审核的模板不进入首版正式上架。 | 阶段0确认 |

## 4. 边界与红线

- V1 暂不接入内容审核；公众人物、他人肖像和二创内容的审核风险记入后台预留项，后续接入前必须补齐规则、投诉流程和责任边界。
- V1 预留模板后台管理窗口；未审核或版权状态不明的模板不进入首版正式上架。
- 一次任务只生成一张图片；多轮修改、换模板和局部重绘通过新版本或新任务完成。
- 生成失败只按已批准的重试策略处理，不自动切换到未批准的模型或供应商。
- 首版低并发、小规模试用；具体并发数和日任务量待确认。
- 人物照片与成品不接 CDN，实际保存时长、删除策略和访问权限待确认。

## 5. 成功指标（可度量）

- 生成成功率 ≥ 85%。
- 单次任务 P95 等待时间 ≤ 120 秒。
- 单次任务成本 ≤ 1 元。
- 每次任务生成 1 张图片，并且用户可以下载或保存成品。
- 首版以低并发小规模试用为范围；具体并发上限待确认。

## 6. 待确认问题与回答

### 2026-11-06 · V1 产品选择

1. **V1 怎样算做成？**
   - 回答：生成成功率 ≥ 85%，单次任务 P95 等待 ≤ 120 秒，用户能下载或保存成品。

2. **一次生成多少内容、采用哪种等待方式？**
   - 回答：表情包和手机壁纸是两个可选择的功能模式，一次只生成一张，按同步等待结果设计。

3. **V1 需要多复杂的创作流程？**
   - 回答：支持多轮修改、换模板、局部重绘和历史版本。

4. **首版准备采用哪种外部能力？**
   - 回答：先接一个图片生成 API；照片和成品暂存本地或单一对象存储，不做 CDN。

5. **首版模板库准备做到什么规模？**
   - 回答：采用平台化方向，模板可以持续上架，并提供后台管理、审核和版权管理。

6. **人物照片、公众人物和内容审核采用哪种边界？**
   - 回答：V1 暂不接入内容审核，预留审核后台窗口和接口；后续接入前再确认公众人物、他人肖像、版权与投诉规则。

7. **出图失败、超时或审核不通过时怎么处理？**
   - 回答：V1 只处理生成失败和超时：自动重试 1～2 次，仍失败就提示原因并允许用户重新生成；审核不在 V1 流程内，后台窗口预留。

8. **V1 的成本、等待时间和规模约束是什么？**
   - 回答：单次任务成本 ≤ 1 元，最长等待 120 秒，首版支持低并发小规模试用。
