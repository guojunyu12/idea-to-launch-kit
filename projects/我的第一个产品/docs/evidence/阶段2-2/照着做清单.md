# 阶段2-2照着做清单

## 1. 打开验收页面

服务已经启动时，浏览器打开：<http://127.0.0.1:8000/test>

页面不需要填写 API。开发测试码固定为 `000000`。

## 2. 登录

1. 邮箱保持 `user@example.com`。
2. 点击「获取验证码」。
3. 验证码保持 `000000`，点击「登录」。
4. 看到“当前身份：user”，算登录通过。

## 3. 走 V7 用户生成闭环

1. 在“V7 用户生成闭环”里选择一个已发布模板。
2. 在提示词框输入：`暖色天空、细腻云朵、清晨氛围，画面干净`。
3. 输出比例先选 `1:1`；也可以改成 `9:16`，或选择“自定义尺寸”填写 512 和 768。
4. 生图模型保持 `商汤图片生成 · sensenova-u1.5-lite`。
5. 点击「生成图片」。
6. 看到结果图片、尺寸、模型和“使用今日免费额度”，算主链路通过。

后台模型配置：运营/管理员展开“后台模型配置”，点击「查看模型配置」；应能看到商汤已启用，千问等其他模型显示“配置保留/未启用”。普通用户点击后应被拒绝。

## 4. 验证权限隔离

1. 点击「测试普通用户后台权限」。
2. 看到“权限验证通过：普通用户不能进入后台模板接口”。
3. 页面下方「刷新公开模板」能看到已发布模板。

## 5. 结果标准

- 生成结果能在页面显示，点击图片地址可下载 PNG。
- 结果尺寸等于页面选择的尺寸。
- 生成失败时页面显示失败原因，免费额度不会被标记为成功消耗。
- 不需要打开 `/docs`，也不需要手写任何 API 请求。
