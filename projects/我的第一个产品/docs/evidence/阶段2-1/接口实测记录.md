# 阶段2-1接口实测记录

日期：2026-11-08

## 环境

- 服务：`http://127.0.0.1:8000`
- 模板：`wallpaper-sunrise`（日出手机壁纸）
- 输入：本地生成的 PNG 测试图，320×240，781 bytes
- 归属头：`X-Owner-ID: owner-a`

## 结果

- `GET /healthz`：200，返回 `{"status":"ok"}`。
- `GET /api/v1/templates?kind=wallpaper`：200，返回日出手机壁纸模板，目标尺寸 1179×2556。
- `POST /api/v1/uploads`：200，返回 `status=available`、SHA-256 和 `upload_id`。
- `POST /api/v1/tasks`：200，返回 `status=succeeded`、`provider=mock`、`version_id`。
- `GET /api/v1/tasks/{task_id}`：200，版本状态为 `succeeded`。
- `GET /api/v1/assets/{version_id}`：200，`image/png`，下载文件为 1179×2556 PNG。
- 将同一任务改用 `X-Owner-ID: owner-b` 查询：404，`error.code=NOT_FOUND`。

结果图见同目录 `mock生成结果.png`。这是 mock provider 的可下载结果，不代表真实模型质量验收。
