# 阶段 3-2 产品验收清单：手机走一遍

## 先启动

1. 在电脑终端确认后端和前端已经启动。
2. 手机和电脑连接同一个 Wi-Fi。
3. 如果只用电脑验收，在浏览器开发者工具把窗口切到 `390px × 844px`。
4. 打开一级页：`http://127.0.0.1:3001`；真机访问时把 `127.0.0.1` 换成电脑的局域网 IP。

## 一级页

1. 看到“表情包”和“手机壁纸”两个独立分类入口，每个入口都有图片、标题和说明。
2. 页面只有一列分类卡片，左右没有被截断，也不能左右拖出额外空白。
3. 点击“表情包”，进入表情包二级页。

## 二级页

1. 页面顶部看到“全部 / 表情包 / 手机壁纸”三项导航；点击“手机壁纸”可以切换到手机壁纸二级页，点击“全部”可以回到一级页。
2. 在当前品类下只看到当前品类的参考模板，模板上方是图片，下方是标题和尺寸。
3. 点选模板后，在“输出比例”中切换几个选项，确认“当前输出尺寸”跟着改变。
4. 点击“上传照片”，选择一张 JPG、PNG 或 WebP 图片；确认文件名出现在上传区。
5. 点击底部箭头，确认状态依次变为“正在上传”“正在生成”“已完成”。真实生成可能需要等待几十秒。
6. 确认“你的作品”区域出现生成图片，右侧任务信息在手机上变成两列信息卡。
7. 点击“下载作品”，确认图片可以保存。
8. 确认页面底部显示“审核后台窗口已预留 / V1 暂不启用内容审核”。

## 产品经理判断标准

- 页面可以单手滚动，主要按钮始终能点到。
- 一级页和二级页都没有横向滚动。
- 分类导航不会消失，不能出现“只能返回浏览器上一页”的情况。
- 失败时能看到中文错误提示，重新选择文件后可以再次提交。

## 验收结果

如果以上步骤都符合，回复：`验收通过`。
