# 阶段2-3照着做清单

## 1. 普通用户验证删除

1. 打开 <http://127.0.0.1:8002/test>。
2. 用 `user@example.com` 和开发测试码 `000000` 登录。
3. 生成一张图片，确认结果出现。
4. 结果删除接口已通过真实冒烟；页面管理区暂保留后台入口。

## 2. 普通用户验证后台隔离

1. 展开“后台模型配置”。
2. 点击「查看模型配置」。
3. 普通用户应看到权限拒绝提示，不能读取后台模型列表。

## 3. 运营/管理员验证配置页

将自己的邮箱加入本地 `.env` 的 `OPERATOR_EMAILS` 或 `ADMIN_EMAILS` 后重启服务，再登录页面：

1. 展开“后台模型配置”，点击「查看模型配置」。
2. 应看到商汤 `sensenova-u1.5-lite` 为“已启用/默认”。
3. 应看到千问 `qwen-image-2.1-turbo` 仍在列表中，但显示“配置保留/未启用”。
4. 依次点击「查看用量摘要」「查看审计记录」「查看模板版本」，能看到对应摘要。

## 4. 结果标准

- 普通用户不能读取后台模型、模板版本、审计和用量。
- 删除自己的结果后，结果下载返回 404，记录状态为 `deleted`。
- 真实生图仍使用商汤，模型 Key 不出现在页面或日志。
