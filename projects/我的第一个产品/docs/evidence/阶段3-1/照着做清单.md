# 阶段 3-1 产品验收清单

## 电脑浏览器

1. 在终端启动后端和前端，打开一级页 `http://127.0.0.1:3001`。
2. 确认一级页只负责选择创作空间，能看到两个独立入口：“表情包”和“手机壁纸”，每个入口上方有图片参考、下方有标题和说明。
3. 点击“表情包”进入二级页 `/category/sticker`；返回一级页，再点击“手机壁纸”进入 `/category/wallpaper`。
4. 在二级页确认模板按当前品类单独展示，卡片上方是生成图片参考，下方是模板标题和尺寸信息；两个品类不会混在同一组里。
5. 选择一个模板，在“输出比例”中选择 `1:1`、`4:3`、`3:2`、`16:9`、`3:4`、`2:3`、`4:5`、`9:16` 等比例；确认“当前输出尺寸”随比例更新。表情包默认 `1:1`，手机壁纸默认 `9:19.5`。
6. 在“上传照片”处选择 JPG、PNG 或 WebP 图片，确认出现文件名和待生成预览。
7. 点击圆形箭头提交，确认状态从“正在上传”变成“正在生成”，最后显示“已完成”。
8. 确认结果区域出现生成图片，右侧能看到任务状态、生成通道、输出比例和耗时。
9. 点击“下载作品”，确认浏览器能保存图片。

## 手机浏览器

1. 用浏览器开发者工具切换到 390px 宽度，刷新一级页。
2. 确认一级页的两个分类卡片变成单列，图片、标题和入口按钮没有横向溢出。
3. 进入任意二级页，确认模板参考图、比例选择、上传控件和结果区域按单列排列，尺寸字段不溢出。
4. 在手机宽度下完成一次选择模板、上传图片和生成操作，确认结果卡片仍完整可读。

## 验收通过标准

- 模板能加载，图片校验提示清楚。
- 生成链路能完成，结果能预览和下载。
- 页面在桌面和手机宽度下都可用。
- 右侧能看到“审核后台窗口”且明确标注 V1 暂不启用内容审核。
